# Glossary — EXP-0007

## A

**Amplitude** — The magnitude of a complex optical field, |E(x,y)|. Determines the intensity of light at each point.

**Artifact** — A feature detected by the analysis pipeline that is not a real physical structure but arises from numerical, algorithmic, or grid-related effects.

## C

**Charge (topological)** — The winding number Q = (1/2π) × ∮ ∇φ · dl, describing how many times the phase winds around a point. Integer values indicate vortices; non-zero charge indicates a topological singularity.

**Complex field** — The optical field represented as E = A × exp(iφ), combining amplitude and phase.

**Curl** — The circulation of phase gradients around a plaquette (2×2 cell), used to compute winding number.

## D

**DBS (DeepBeamScan)** — The feature detection algorithm used in EXP-0007. Detects phase singularities using winding-number topology via 2×2 plaquette curl calculation.

**Defect (code)** — A flaw in the source code that causes incorrect behavior. EXP-0007 identified 6 defects (D1-D6).

**D01 null** — A control field with circular-Gaussian random phases. Used to test whether the lattice produces fewer features than random noise.

**D02 null** — A matched-spectrum surrogate field (|FFT2(E)| preserved, random phase). Used as the primary statistical control for comparing lattice features against the null expectation.

## F

**Feature** — A point detected by DBS as a potential vortex (phase singularity). Features may or may not correspond to real vortices.

**Fresnel propagation** — An approximation for optical propagation valid when z >> aperture size. Uses H = exp(±iπλz(kx²+ky²)).

## G

**Grid-locking** — A detector artifact where the pixel grid aligns with the structure being measured, causing systematic undercounting or overcounting. Grid-locked measurements depend on pixel alignment.

## P

**Phase** — The wave position component of a complex optical field, φ(x,y), in radians wrapped to [-π, π].

**Phase singularity** — A point where the field amplitude goes to zero and the phase is undefined (a vortex). In practice, DBS detects phase gradients, not all of which are true singularities.

**Phase wrapping** — The process of constraining phase differences to [-π, π], which can introduce discontinuities at ±π boundaries.

## R

**Resolution** — The grid size used in simulation (e.g., 256×256, 512×512). Lower resolution = fewer pixels = coarser representation.

**Resolution convergence** — A property of valid physical measurements: the measured quantity should stabilize (not change systematically) as resolution increases.

## T

**Threshold** — A cutoff value used to decide whether a detected feature counts. DBS uses |charge| > 0.5 as the default threshold.

**Topological charge** — See Charge (topological).

## V

**Vortex** — A point in a complex field where the amplitude goes to zero and the phase winds by 2π (integer winding number). True vortices require |E|→0 at the core.

**Vortex crystal field** — The specific lattice used in EXP-0007: a periodic array of 48 phase singularities (6 rows × 8 columns) generated by `vortex_crystal_field()`.

## W

**Winding number** — The number of times the phase winds around a point (integer). Computed by integrating the phase gradient around a closed loop.

**Winding count** — The total number of non-zero winding features in a 2D field. MethodB winding_count uses np.mod formula (buggy with double-wrap); MethodA uses np.angle(exp(iδ)) formula (correct).
