# R14 — Definitive Vortex Validation

## Experiment Description

R14 is the central validation study for EXP-0007. It tested whether the R13 finding of 113 vortices at z=+1280 µm represents genuine topological creation through 24 controlled validation phases.

## Parameters

- Grid: 256×256
- Lattice: 6×8 = 48 design vortices
- Propagation: z=0 → z=+1280 µm
- Detector: DeepBeamScan (DBS)

## Key Results

- DBS at z=0: 48
- DBS at z=+1280: 113 (independently verified)
- MethodC zero search: 0/20 confirmed (NOT at amplitude zeros)
- Threshold range: 0→102
- Resolution convergence: 328→1,328→5,742 (NO)
- Null distribution: 113 at 0th percentile
- Detector: 9-19× overcount on known topology

## Verdict

**DETECTOR + GRID-LOCKING ARTIFACT**

The 113 features are real phase variations but NOT physical vortex creation. They are detector artifacts amplified by grid alignment.
